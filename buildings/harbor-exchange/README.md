# Harbor Exchange

Harbor Exchange is a fictional two-level ferry, market, and community venue used
by Venue Bootstrap v0. It intentionally differs from the four-level Asterion
medical benchmark:

- two floors with different footprints;
- three connector types (lift, stairs, and escalator);
- transit, market, community, cafe, gallery, and terrace destinations;
- a short mezzanine bridge rather than Asterion's repeated hospital floors;
- three venue-specific localization anchors.

The source is compiled with the same deterministic compiler and loaded by the
browser as a runtime package artifact.
