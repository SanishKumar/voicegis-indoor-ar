# Demo media

The Meridian Park campus, phone overview and Level 1 ward stills were
captured from the visitor app. The desktop walkthrough orbits the campus,
opens Main Hospital, switches to Level 1 and zooms into the ward. The phone
walkthrough follows the Cardiology Clinic route from Main Gate into Main
Hospital using the route preview controls. The Inspector image shows the
earlier campus design.

The hospital interior close-up shows the locally bundled floor by neutralize,
opened from the campus map's graphics menu.

The camera and AR images use a corridor rendered at the same camera pose
as the simulated browser input. The direction overlay, floor confirmation and route graphics come
from the app. Both images carry the **SIMULATED SCENE · PRODUCT INTERFACE**
label.

To recreate the camera views, run `npm run dev` and open
`/scripts/showcase.html?checkin=voicegis://asterion/g/east#/visitor`.
Navigate to Civic Plaza Entrance, open **Camera view**, and choose
**I'm facing the corridor**. For the immersive image, choose **Start AR**
and confirm the simulated floor.
